Blasher

Basic firmware flasher. Drop in a .bin and the target is reset into its ROM bootloader, erased, programmed, verified and restarted — hands free, over the STM32 UART bootloader (AN3155).

This browser cannot talk to serial devices. Blasher needs the Web Serial API — use desktop Chrome, Edge or Opera over https:// or http://localhost.
